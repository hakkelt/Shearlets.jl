Shearlets.jl

Translation-invariant discrete shearlet transforms of images and volumes, computed on the DFT grid.

A shearlet system splits an image by scale, like a wavelet, and each scale further by direction. Each subband then holds the edges of one scale and one direction, so images with curved edges have sparser coefficients than with separable wavelets. Every subband has the size of the input. The package has three systems: BandlimitedShearlets (2-D and 3-D), NSSTShearlets (2-D) and CompactShearlets (2-D and 3-D); Which system compares them.

Installation

Shearlets.jl and its dependencies MultiscaleFilterBanks.jl and AbstractMultiscaleTransforms.jl are not registered yet. Clone the three repositories side by side and develop them into your environment:

git clone https://github.com/hakkelt/AbstractMultiscaleTransforms.jl AbstractMultiscaleTransforms
git clone https://github.com/hakkelt/MultiscaleFilterBanks.jl MultiscaleFilterBanks
git clone https://github.com/hakkelt/Shearlets.jl Shearlets
using Pkg
Pkg.develop([PackageSpec(path = "AbstractMultiscaleTransforms"),
             PackageSpec(path = "MultiscaleFilterBanks"),
             PackageSpec(path = "Shearlets")])

Example

analyze returns the subbands stacked along a new last axis, and subband_layout says what each one is:

julia> using Shearlets, Random

julia> Random.seed!(1); x = randn(256, 256);

julia> sys = BandlimitedShearlets(scales = 4);

julia> c = analyze(sys, x); size(c)
(256, 256, 61)

julia> subband_layout(sys, size(x))[10]
ShearletIndex(scale = 2, cone = 1, shear = (2,))

julia> x ≈ synthesize(sys, c)
true

Related packages

Contourlets.jl (2-D contourlets) and Surfacelets.jl (3-D surfacelets) are directional transforms of the same family. All three are built on MultiscaleFilterBanks.jl, whose FilterPair and CDF97 Shearlets re-exports, and implement the interface of AbstractMultiscaleTransforms.jl (analyze, synthesize, make_workspace, subband_layout, ...), whose names Shearlets re-exports too.
