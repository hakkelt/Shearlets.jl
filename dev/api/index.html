Module

Shearlets.Shearlets — Module
Shearlets

Discrete shearlet transforms of images, translation invariant and computed on the DFT grid.

Quick reference

FunctionDescription
shearlet_forward / shearlet_inverseTransform and its inverse; a streaming form of each
make_shearlet_workspaceMasks, plans and buffers for repeated transforms
shearlet_layout / shearlet_nsubbandsWhat each subband is
shearlet_spectraThe frequency responses, for inspection

Shearlet systems:

  • BandlimitedShearlets: Häuser & Steidl's FFST, band-limited Meyer shearlets, a Parseval frame;
  • NSSTShearlets: Easley, Labate & Lim's nonsubsampled shearlet transform, an à trous pyramid with shearing filters;
  • CompactShearlets: ShearLab 3D's compactly supported digital shearlets, with dual-frame reconstruction.

Every system is a set of real, point-symmetric masks on the DFT grid, so a transform is one FFT plus one inverse FFT per subband. The coefficients of x form one array of size (size(x)..., nsubbands).

MultiscaleFilterBanks.MultiscaleFilterBanks — Module
MultiscaleFilterBanks

Shared building blocks for multiscale, multidirectional filter-bank transforms.

This package holds the pieces that are neither 2-D nor 3-D specific and are used by Contourlets.jl (the 2-D contourlet / nonsubsampled contourlet transform), Surfacelets.jl (the 3-D nonsubsampled and decimated surfacelet transforms) and Shearlets.jl (2-D and 3-D shearlets):

ExportDescription
FilterPair1-D biorthogonal analysis/synthesis low-pass filter pair
CDF97The CDF 9/7 filter pair used by the pyramid stages
upsample_filterÀ trous ("with holes") filter upsampling
ThreadingPolicy, Auto, Enabled, DisabledThreading policy types

It also carries the internal helpers both downstream packages share: the element-type convention (_data_eltype / _filter_eltype), the threaded loop over independent FFTs (_foreach_chunk / _chunked_sum!), the scoped FFTW thread count (_with_fftw_threads), the boundary index folding (_clamp_idx) and the à trous pyramid filter construction (_nsp_atrous_filters) and its frequency responses (_nsp_responses), and the mask-bank engine that runs a nonsubsampled pyramid plus directional banks as products on the DFT grid (_MaskBankEngine).

Its only non-stdlib dependencies are Polyester (the task runner), NestedThreading (the FFTW thread budget) and FastBroadcast (the engine's same-size products).

Shearlet systems

Shearlets.ShearletSystem — Type
ShearletSystem

Abstract type of the shearlet systems: a description of the frame that does not depend on the data size. The masks themselves are built for one size and element type by make_shearlet_workspace.

Subtypes: BandlimitedShearlets, NSSTShearlets, CompactShearlets.

source
Shearlets.BandlimitedShearlets — Type
BandlimitedShearlets(; scales = 0, smooth = false, alpha = 1)

The band-limited cone-adapted shearlet system of Häuser & Steidl's Fast Finite Shearlet Transform (FFST): Meyer-type windows on the full DFT grid, a Parseval frame whose inverse is its adjoint. Works on 2-D and 3-D data (cones become the three pyramids around the axes).

  • scales: number of scales J (0 picks ⌊log₂(min(size)) / 2⌋). Scale j has s = 2^(j-1) shears per side of each cone; in 2-D that is 4s shearlets, two of them seam shearlets glued across the cones.
  • smooth: use the tensor-product lowpass of Guo & Labate's construction, which makes the seam shearlets smooth (and better localised in space) at the price of a less cone-aligned lowpass.
  • alpha: the anisotropy of α-shearlets, 0 ≤ α ≤ 2: s = round(2^((2-α)(j-1))) shears per side. α = 1 is parabolic scaling (shearlets), α = 2 keeps one shear per side at every scale (wavelet-like), α → 0 approaches ridgelets.

Every subband has the size of the input; real input gives real subbands.

source
Shearlets.NSSTShearlets — Type
NSSTShearlets(; directions = [3, 3, 4, 4], filter_size = nothing, pyramid = CDF97)

The nonsubsampled shearlet transform (NSST) of Easley, Labate & Lim (2008): a nonsubsampled Laplacian pyramid with length(directions) levels, each split by shearing filters into 2^directions[j] directional subbands (scale j = 1 is the coarsest). Every subband has the size of the input.

  • directions: log₂ of the number of directional subbands per scale, coarse to fine, each at least 2: 2^(d-2) shears per side of each cone, two seam subbands glued across the cones.
  • filter_size: the side L of the spatial shearing filters, per scale (a vector) or for all scales (an integer). Larger filters resolve directions better near the origin; smaller ones are more local. 0 samples the windows on the image's own DFT grid (the frequency-domain variant). The default is 32 for the scales coarser than the two finest, which use 16.
  • pyramid: the 1-D filter pair of the à trous pyramid; it must be symmetric with an odd number of taps.

The frame is not tight: shearlet_inverse sums the directional subbands of each level and inverts the pyramid.

source
Shearlets.CompactShearlets — Type
CompactShearlets(; scales = 4, shear_levels = ceil.(Int, (1:scales) ./ 2), qmf, fan)

The compactly supported digital shearlets of ShearLab 3D (Kutyniok, Lim & Reisenhofer, 2016), without subsampling: shift invariant, every subband the size of the input. Spatially compact filters, at the price of a frame that is not tight — the inverse uses the dual filters.

  • scales: number of scales J, coarse to fine.
  • shear_levels: per scale the level d: shears k = -2^d, …, 2^d in each cone, 2(2^(d+1) + 1) subbands per scale. The default is parabolic scaling.
  • qmf: the 1-D lowpass of the quadrature mirror pair (symmetric, odd length); the highpass is its modulation (-1)^n h[n]. The default is ShearLab's 9-tap maximally flat filter.
  • fan: the 2-D fan filter P as a matrix of taps with the origin at its centre, passing the horizontal fan |ω₂| < |ω₁|; the default is the maximally flat fan filter of order 4 of da Cunha, Zhou & Do (2006).

The two cones overlap at the seam lines (|k| = 2^d in both), as in ShearLab.

On 3-D data the cones are the three pyramids around the axes and a shearlet has a shear (k₁, k₂) against each of the other two axes, 3(2^(d+1) + 1)² subbands per scale (ShearLab 3D's Definitions 3.3–3.4).

Shearlets.ShearletIndex — Type
ShearletIndex{M}

Where a subband sits in a shearlet system on an N = M + 1-dimensional grid:

  • scale: 0 for the lowpass, else 1, …, J from coarse to fine;
  • cone: 0 for the lowpass, else the axis the frequencies of the subband are largest along (1: the horizontal cone |ω₂| ≤ |ω₁| of a matrix, whose rows are axis 1; 2: the vertical cone);
  • shear: the shear of each of the other M axes against cone.

A subband of cone c and shear k at scale j collects the frequencies with ω_e / ω_c ≈ -k / 2^(j-1) for the other axes e. Where a shear reaches the seam between two cones (|k| = 2^(j-1) for band-limited shearlets), the subband is glued across the seam and listed under the lower cone.

Shearlets.shearlet_spectra — Function
shearlet_spectra(system, dims; T = Float64, synthesis = false) -> Array{T}

The frequency responses of all subbands of system on the full, unshifted DFT grid of a dims array: an array of size (dims..., n), in shearlet_layout order. Subband i of x is real(ifft(spectra[.., i] .* fft(x))).

With synthesis = true, the masks the inverse applies instead: x is real(ifft(sum(spectra .* fft(subbands)))). For a Parseval system the two are equal.

Transforms

Shearlets.shearlet_forward — Function
shearlet_forward(x, system::ShearletSystem; workspace = nothing, threading = Auto()) -> Array

Shearlet transform of x: an array of size (size(x)..., n) whose slice i along the last axis is the subband shearlet_layout(system, size(x))[i] (the lowpass first). The transform is invariant under circular shifts of x; real input gives real subbands. The subbands are computed in parallel unless threading = Disabled().

Examples

julia> using Shearlets, Random

julia> x = randn(Xoshiro(1), 64, 64);

julia> c = shearlet_forward(x, BandlimitedShearlets(scales = 2));

julia> size(c)
(64, 64, 13)

julia> sum(abs2, c) ≈ sum(abs2, x)   # a Parseval frame
true
source
shearlet_forward(f, x, system::ShearletSystem; workspace = nothing)

Streaming shearlet transform: calls f(i, band) for every subband i in shearlet_layout order, reusing one buffer between calls, so the coefficient set is never held at once. band is valid only until f returns — copy or reduce it there. The calls come one at a time, from the calling task.

Shearlets.ShearletWorkspace — Type
ShearletWorkspace{Td, Tf, N}

Masks, FFT plans and buffers of a shearlet system at one data size and element type Td (filters in Tf = real(float(Td))). Build with make_shearlet_workspace and pass it as workspace to shearlet_forward / shearlet_inverse to keep repeated calls out of the allocator.

A workspace holds scratch buffers, so it must not serve two transforms at the same time; it threads internally instead.

source

Build the masks, buffers and FFT plans of system for data of element type T (real or complex) and size dims. flags are the FFTW planner flags.

FilterPair{T}

A 1-D biorthogonal filter pair holding an analysis (h) and synthesis (g) low-pass filter vector. Both filters are stored as coefficient vectors whose centre tap is at index ceil(Int, length/2) (1-based Julia indexing).

MultiscaleFilterBanks.CDF97 — Constant
CDF97 :: FilterPair{Float64}

The standard CDF 9/7 biorthogonal filter pair. The 9-tap analysis filter and 7-tap synthesis filter are the JPEG2000 default low-pass filters.

julia> using MultiscaleFilterBanks

julia> isapprox(sum(CDF97.h), 1.0; atol = 1e-12)
true

julia> isapprox(sum(CDF97.g), 2.0; atol = 1e-12)
true

MultiscaleFilterBanks.upsample_filter — Function
upsample_filter(h::AbstractVector, factor::Int) -> Vector

Insert factor - 1 zeros between every tap of h. This implements the "à trous" (with holes) upsampling used by the nonsubsampled pyramid and the nonsubsampled directional filter banks to avoid downsampling at coarser levels.
